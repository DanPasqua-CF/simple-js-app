# Introduction
This project allows a user to search for a Pokemon; click on the Pokemon card; view information about the selected Pokemon; and close out of the modal. I've included a link to the original Pokemon API index for reference and credit.

Using Bootstrap and jQuery, I was able to, with minimal CSS customization, design the page, and utilize Bootstrap classes to implement most of the application's functionality.

## Technologies
This application includes the following tools:
* jQuery
* Bootstrap
* JS and CSS minified files
